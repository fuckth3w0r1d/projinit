# 文档导航

此页是目标项目的导航骨架，接入时按实际文档调整说明。先阅读根 [README](../README.md) 了解项目用途和使用入口，再按以下顺序阅读。

## 阅读顺序

1. [需求规格](spec.md)：了解当前有效的目标场景、产品行为、项目约束和验收要求。
2. [架构说明](map.md)：了解已经实现的模块职责、状态所有权、依赖和关键协作路径，并通过源码入口继续阅读实现。
3. 根据具体问题查找项目已有的操作指南或模块说明；新内容需要独立阅读时再建立相应目录，并在本页补充入口。

当前文档均位于 `docs/` 根目录，没有文档子目录。架构解释放在 `map.md`；实际操作指导确实需要独立篇幅时再建立 `guides/`，模块说明需要拆分时再建立 `architecture/`。

各 Git 分支沿用相同路径，文档随代码一起审查和合并。任务计划、未实施方案、执行结果和审查记录保存在会话、Issue 或 PR。新增、移动、删除文档或改变目录职责时，同步更新本页。
